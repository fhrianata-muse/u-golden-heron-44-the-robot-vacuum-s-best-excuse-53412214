One line, 92 characters — the excuse a robot vacuum gives for missing a spot:

> My dustbin is full of yesterday's spot. I can't eat another crumb until somebody empties me.

`main.py` holds the line, checks it against the 1–140 character single-line gate at run time, and writes it to `/output/entry.txt`.
